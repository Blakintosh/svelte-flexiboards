# @flexiboards/react

## 1.0.0

Initial React 18 and 19 adapter for the shared Flexiboards engine.

- Board, target, widget, grab, resize, add, delete, dashboard, and sortable components, with reactive controller hooks.
- Server rendering, hydration, client storage loading with suspense, responsive layouts, and late widget declarations.
- CSS and spring motion presets, committed layout callbacks, and destination-size drop flights.
- Grid rows and cells with one-based ARIA indices, decorative drag previews excluded from assistive technology, keyboard focus retained after moves, and live announcements in StrictMode.
