# @flexiboards/core

The framework-agnostic engine behind [`@flexiboards/svelte`](https://www.npmjs.com/package/@flexiboards/svelte) and [`@flexiboards/react`](https://www.npmjs.com/package/@flexiboards/react): board, target and widget controllers, the flow and free grids, the pointer and keyboard interaction model, the drop preview, layout export and import, and the animation adapters. The adapters bind these to a component tree.

Install an adapter rather than this package unless you are writing one. Docs: [flexiboards.dev](https://flexiboards.dev/)
